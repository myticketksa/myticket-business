# MyTicket Business

Production frontend for the MyTicket organizer, talent, and vendor portal.

**Source of truth:** [Design system](./docs/MyTicket-Design-System-Specification.md), [Frame inventory](./docs/MyTicket-Business-Frames.md), [Mock users](./docs/mock-users.md), and `.cursor/rules/`.

All other project markdown lives in [`docs/`](./docs/).

Stack: React, TypeScript, Vite, Tailwind CSS v4, shadcn/ui, Redux Toolkit, Yup.

```bash
npm install
npm run dev
npm run build
```

Dev galleries: `/dev/tokens`, `/dev/primitives`. Sign in: `/auth` (see [mock users](./docs/mock-users.md)). App shell: `/app` (dev role switcher). Scanner: `/scanner`.
